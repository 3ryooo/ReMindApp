# Re:Mind ランダムリマインダー (仮)

## 概要

このアプリは、ユーザーが登録した言葉やフレーズを、設定した時間にランダムに通知することで、日々のモチベーション維持や大切なことの再認識をサポートすることを目的としたiOS向けアプリケーションです。

## 主な機能 (予定)

* 言葉の登録・編集・削除
* 登録した言葉のリスト表示
* 各言葉に対するリマインド通知のON/OFF設定
* 指定した時間に、ONになっている言葉の中からランダムで一つを通知
* 通知する時間帯の設定

## 開発環境 (予定)

* 言語：Swift
* フレームワーク：SwiftUI
* IDE：Xcode
* ターゲットOS：iOS (最新版を想定)
* データ永続化: SwiftData
* ユーザーフロー図：FigJam
* ワイヤーフレーム：Goodnotes+Marvel
* テスト：XCTest,SwiftTest
